# Muhammad Measm Raza Portfolio

Climate-Tech Entrepreneur & Global Impact Builder

## About

Portfolio website for Muhammad Measm Raza, Founder of Meetech Labs. Building verified climate impact, scalable technology, and globally distributed companies.

## Tech Stack

- Next.js 16 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Contact API

Contact form backend now runs inside Next.js API route:

- Endpoint: `/api/contact`
- File: `app/api/contact/route.ts`

Required environment variables:

- `RESEND_API_KEY`
- `ADMIN_EMAIL`
